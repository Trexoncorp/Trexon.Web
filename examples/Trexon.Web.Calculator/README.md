# Калькулятор в одном файле

Весь код — [Program.cs](Program.cs), 44 строки с комментариями. Три строки создают приложение,
подключают маршруты и запускают сервер. Swagger, JSON, проверка параметров и обработка
ошибок подключены библиотекой автоматически.

## Запуск

Из корня репозитория:

```sh
dotnet run --project examples/Trexon.Web.Calculator
```

Откройте [Swagger](http://127.0.0.1:5081/docs): выберите операцию, нажмите **Try it out**,
заполните `a` и `b` и выполните запрос. Схема API доступна по `/openapi.json`.

В коде запуска указан только порт:

```csharp
var web = TrexonApp.Create(args, api => api.Title = "Calculator API");
web.AddRoutes<CalculatorRoutes>();
await web.RunAsync(5081);
```

Это начало полного [Program.cs](Program.cs); класс маршрутов и модели находятся ниже
в том же файле. Для другого порта замените `5081` в последней строке.

## Запросы

| Запрос | result |
| --- | --- |
| `/calculator/add?a=10&b=5` | 15 |
| `/calculator/subtract?a=10&b=5` | 5 |
| `/calculator/multiply?a=-3&b=2` | -6 |
| `/calculator/divide?a=7&b=2` | 3.5 |

```sh
curl 'http://127.0.0.1:5081/calculator/add?a=10&b=5'
```

Ответ:

```json
{"operation":"Add","a":10,"b":5,"result":15}
```

`a` и `b` обязательны, находятся в диапазоне от −1 000 000 до 1 000 000.
Отсутствующее/нечисловое значение, неизвестная операция, деление на ноль или бесконечный
результат дают HTTP 400 в формате Problem Details. Ошибки параметров содержат `errors`.

## Что показывает пример

- `[Routes]` и `[Get]` задают маршрут без базового контроллера.
- `[Tag]`, `[Summary]` и `[Response]` описывают API в Swagger прямо рядом с методом.
- `BindRequired` и `Range` задают проверку query-параметров и отражаются в OpenAPI.
- `HttpError` возвращает понятную ошибку через встроенный обработчик.
- `ValueTask<Calculation>` сохраняет асинхронный контракт; само вычисление не требует I/O.
- `RunAsync(5081)` запускает HTTP на `127.0.0.1:5081` и ожидает остановки через Ctrl+C.

Для большего сервиса есть [полный пример](../Trexon.Web.Sample/README.md) с БД,
аутентификацией, модулями и WebSocket. [Руководство библиотеки](../../docs/README.md).
