Connecting to protected endpoints

Sign in with your username and password, paste a Bearer token or use an API key. Available methods follow the application's authentication modules.

For token and API-key connections, the console obtains a single-use, 30-second connection ticket. The endpoint still checks its usual authentication scheme, roles and policies. Credentials are never added to the URL or saved in browser storage.

Cookie sign-in additionally requires HTTPS and UseCookies(). Existing session cookies are sent automatically in Default mode. Use HTTPS outside local development.

Connect again after signing in: access is checked when the connection opens.
